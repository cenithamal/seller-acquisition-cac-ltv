# Seller Acquisition CAC/LTV Analysis

## Business Question

## Data Source
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) + the companion Marketing Funnel by Olist dataset (Kaggle).
